# HTML Portfolio – Week 01 Assignment

## About the Project
A personal portfolio webpage built using HTML5 only as part of Week 01 of the GIG Skill Boost – Front-End Development Program.

The page includes different sections to present a portfolio, services, projects, contact information, and a contact form.

## Technologies Used
- HTML5

## Features
- Hero section.
- Services section.
- Portfolio gallery.
- Contact form.
- Contact information.
- Footer with brand images.
