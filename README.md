## About the Program

This repository documents my learning journey throughout the **Front-End Development Course** under the **GIG Skill Boost Program**, implemented by Nile University's Innovation, Entrepreneurship, and Competitiveness Centre (IECC), in partnership with Banque Misr Foundation for Community Development.

The repository includes weekly learning materials, practical assignments, coding exercises, and projects developed throughout the program.

## Learning Objectives

- Build a strong foundation in Front-End Web Development.
- Develop responsive and user-friendly web interfaces.
- Strengthen JavaScript programming skills.
- Learn React and component-based development.
- Understand TypeScript fundamentals.
- Work with APIs and asynchronous data.
- Build and deploy complete web applications.
